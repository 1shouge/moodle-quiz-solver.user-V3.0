# 答题助手 v3：错题本 + 满分冲刺

> 适用脚本：`userscripts/moodle-quiz-solver.user.js`（v3.0.2）
> 旧版备份：`userscripts/legacy/moodle-quiz-solver-v2.1.0.user.js`

v3 在 v2.1.0 的基础上加了两件事：

1. **错题本**：按「题干文字 + 选项文字」记录，不按 ABCD。
   Moodle 每次重考都会打乱选项顺序，按字母记必然错位。
2. **满分冲刺**：自动答完 → 交卷 → 从回顾页学习错题 → 自动重考，
   直到满分或用完允许的轮数。

同时修复了 v2.1.0 的两个实测 bug：多选答案被 `click` 二次切换掉、
提交时触发主题 autosave 把刚填的答案冲掉。

v3.0.1 修复判断题：Moodle 4.x 的判断题 `<label>` 带 `class="ms-1"`，旧版清理图标时
把 label 一起删了，导致「对/错」读成空字符串。现在只删图标，并把
「对 / 正确 / True / T」视为同一种答案。

v3.0.2 修复 v3.0.1 引入的「correct is not defined」：判断题重构时漏改了一处
多选分支的变量名，导致多选题直接抛错停机。已修正并补了多选回归测试。

---

## 1. 安装 / 升级

1. 打开 Tampermonkey → 找到旧的答题助手 → 删除或停用（**不要同时启用两个**）。
2. 新建脚本，粘贴 `userscripts/moodle-quiz-solver.user.js` 的全部内容，保存。
3. 打开任意 `/mod/quiz/` 页面，左下角会出现「答题助手 v3」面板。

旧版的 `scnu_quiz_ai_cfg_v2` 配置会被自动沿用；错题本是新键
`scnu_quiz_wrongbook_v1`，不会和旧数据冲突。

---

## 2. 先配置模型接口

面板下半部分：

| 字段 | 说明 |
|---|---|
| 取答案方式 | `直连接口`：浏览器直接请求 OpenAI 兼容接口；`本地 DSH 桥`：走 DSH 插件的本地桥 |
| 接口地址 | 填到 `/v1` 为止，例如 `https://api.deepseek.com/v1`；脚本会自动补 `/chat/completions` |
| API Key | 直连时必填（本机/免费接口可留空） |
| 模型名 | 例如 `deepseek-chat` |
| 每批题数 / 请求间隔 | 默认 5 题一批、600ms 间隔；接口限流时把批数调小、间隔调大 |
| 满分冲刺最多轮数 | 默认 8，脚本绝不会超过这个轮数 |

> 只答选择题、且错题本已经记全时，脚本会**直接查错题本**，不再请求模型。

## 3. 三种用法

### 🚀 放任自流（不自动交卷）

点一下 → 从当前页开始自动抓题、作答、翻页。

- 到「全部提交并结束」页面会**停下**，按钮会高亮，**交卷仍然由你点**。
- 这是默认的安全模式，适合只想省掉逐题作答的场景。

### 🏁 满分冲刺（自动交卷 + 自动重考）

点一下 → 弹窗确认 → 脚本自动完成：

```
学习历史回顾（只读 GET）
  → 重新作答
  → 逐页作答并提交
  → 提交试卷
  → 在回顾页记录错题、读成绩
  → 未满分且未到轮数上限：自动重考
  → 满分：停止，保存错题本
```

停止条件（任一满足即停手，不会硬闯）：

- 已满分；
- 达到「满分冲刺最多轮数」；
- 回顾页读不到成绩；
- 交卷后没有进入回顾页（例如老师关闭了回顾）——此时重考也学不到东西，直接停；
- 页面提示次数用完 / 测验关闭 / 没有权限；
- 你点了「■ 停」。

> 交卷不可逆。开始前的确认框会写明轮数，请先确认测验允许重考、
> 评分方法是「最高分」或你愿意承担当前这次成绩。

### 只答本页（不翻页）

只抓当前页、填当前页，不提交、不翻页。适合先看看脚本会选什么。

### 其他按钮

- **📚 学习历史错题**：把入口页上所有「回顾」链接抓一遍，只读，不提交。
- **📕 查看错题本**：按题目文字列出已知错误/正确选项。
- **🗑 清空**：清空错题本（配置和缓存不动）。

## 4. 错题本是怎么记的

Moodle 回顾页默认**只标出你选过的选项对不对**：

- 选中且正确 → 绿色 `correct`；
- 选中且错误 → 红色 `incorrect`；
- **没选的正确项不会显示**（本校默认如此）。

因此 v3 的学习规则是：

| 情况 | 学到什么 |
|---|---|
| 整题「正确」 | 选中的就是完整正确答案；本题其余选项全部记为错误（权威数据，覆盖旧记忆） |
| 单选「错误」 | 选中的那一项一定错 |
| 多选「部分正确」 | 选中的正确项记为正确；如果已选项全对但被判错，记一个「上次漏选」提示 |
| 多选「错误」 | 选中的正确项记为正确，选中的错误项记为错误 |
| 未作答 | 没有可学的选项信息，跳过 |

下一次作答时：

- 单选：排除已知错误项后只剩一个 → 直接选；有已知正确项 → 直接选。
- 多选：已知正确项必选，已知错误项必不选，剩下的交给模型。
- 如果题目/选项被老师改过、旧记忆和当前选项**全部冲突**，脚本会忽略这条记忆，
  不会拿旧答案硬套新题。

数据存在 `localStorage`：

| 键 | 内容 |
|---|---|
| `scnu_quiz_wrongbook_v1` | 错题本 |
| `scnu_quiz_run_v2` | 当前运行状态（授权、轮数、阶段） |
| `scnu_quiz_ai_cfg_v2` | 模型配置 |
| `scnu_quiz_ai_cache_v2` | 非选择题答案缓存 |

换 attempt、刷新页面都不会丢；换浏览器/换电脑不会同步。

## 5. 模型不返回答案时：自动试错

接口失败、返回空、JSON 解析不出某题、或者模型给的选项刚好都在错题本里
（`wrong`）时，**选择题不会再空着提交**：

| 题型 | 试错策略 |
|---|---|
| 单选 / 判断 | 优先已知正确项；否则从「不在错题本 wrong 里」的选项里试第一个 |
| 多选 | 已知正确项必选，再补一个未知项；如果什么都不知道，先只试一个 |
| 填空 / 数值 / 简答 | 没有选项，仍然留空（这类题试错没有意义） |

回顾页会把这次试错的结果记下来：

- 试错的选项对了 → 记进 `correct`；
- 试错的选项错了 → 记进 `wrong`，下一轮不会再选它；
- 多选只试了一个、被判「部分正确」→ 记 `hintMissing`，下一轮继续补。

所以即使模型一直不返回答案，脚本也能靠「试错 + 回顾页反馈」逐轮逼近，
不会每轮都交白卷。面板的报告里会标 **「模型未给答案，已试错」**。

> 有倒扣分、或者测验不允许重考时，请谨慎使用；试错会真实提交答案。

## 6. 推荐流程

1. 打开测验入口页（`view.php?id=...`）。
2. 点「📚 学习历史错题」，把以前答过的回顾扫一遍（可选，但强烈建议）。
3. 点「🏁 满分冲刺」，确认轮数后开始。
4. 脚本自动跑；中途想停就点「■ 停」——正在等待模型返回时也会在返回后
   **丢弃本页答案、不提交**。
5. 面板显示「🎉 已满分」即完成；错题本会保留，下次同题可直接用。

如果只想答一次，用「🚀 放任自流」，最后自己交卷。

## 8. 常见问题

**Q：面板没出现？**
确认地址是 `/mod/quiz/` 下的页面；Tampermonkey 里脚本已启用；刷新一次。

**Q：提示「还没填 API Key」？**
直连模式需要 Key。可以填 Key，或把「取答案方式」切成「本地 DSH 桥」。
本机地址 / pollinations 之类的免费接口不强制 Key。

**Q：模型接口失败/返回不是 JSON？**
脚本会对该批题退回「排除法」（只用错题本）。免费接口不稳定时建议换自己的 API。

**Q：多选题总是少选？**
先跑一次「📚 学习历史错题」；如果回顾页被判「部分正确」，错题本会提示
「上次漏选」，下一轮模型会补选。也可以在「追加提示」里写课程背景。

**Q：判断题填不上 / 没选中？**
v3.0.1 已修复：Moodle 4.x 判断题的选项文字在 `<label class="ms-1">` 里，
旧版清理图标时把整个 label 删掉了。请把脚本更新到 v3.0.1 后刷新作答页。
如果还出现，面板报告里会写出「当前选项：…」，把这一行发来即可定位。

**Q：判断题模型回「正确/错误」，但选项写「对/错」怎么办？**
脚本按语义匹配，`对 / 正确 / 是 / True / T / √` 和
`错 / 错误 / 否 / False / F / ×` 都能对上；模型回 A/B 也可以。

**Q：满分冲刺交卷后停在入口页，提示「没有进入回顾页」？**
老师关闭了回顾或当前账号没有回顾权限，脚本无法学习错题，所以主动停机。
请手动查看成绩；这种情况下重考也不会进步。

**Q：会不会把分数改高？**
不会。脚本只操作当前页面上的表单，提交的是真实作答；分数由 Moodle 判定。

**Q：能同时开两个答题脚本吗？**
不要。会重复填答案/重复提交。

## 9. 使用边界

- 只在你**自己已登录的浏览器**里操作当前页面，不代登录、不保存口令。
- 「放任自流」绝不自动交卷；「满分冲刺」只在**你点击按钮并确认**后自动交卷。
- 不伪造分数、不修改服务端数据。
- 请遵守课程规则；因自动交卷产生的成绩后果由使用者承担。
